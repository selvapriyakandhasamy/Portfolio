SELVAPRIYA K - PORTFOLIO

Run:  npm install  then  npm run dev   (build: npm run build)

EDIT YOUR DETAILS: top of src/App.jsx (email, GitHub, LinkedIn, college, degree, resume).
- GitHub, LinkedIn, college and project links stay hidden until you replace the "your-..." placeholders.
- Resume: put resume.pdf in public/ and set resume: "/resume.pdf".
- Photo: none by default. To show one, add public/profile.jpg and set photo: "/profile.jpg" in src/App.jsx. Resume: replace public/resume.pdf.
- Certificates: PDFs and preview images are in public/certificates/. To add one, copy both files there
  (same name, .pdf and .jpg) and add an entry to the certificates list in src/App.jsx.
- Set SHOW_SCORES = false in src/App.jsx to hide percentages.
